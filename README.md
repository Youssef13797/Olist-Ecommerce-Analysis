# 🇧🇷 Olist Brazilian E-Commerce Analytics

## 📌 Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on the Brazilian e-commerce dataset from Olist. The goal is to extract actionable business insights regarding sales trends, customer geography, and operational metrics using interactive visualizations.

## 🎯 Objectives
* **Data Unification:** Merged multiple relational datasets (Orders, Customers, Products, Payments, etc.) into a single comprehensive DataFrame.
* **Data Cleaning:** Handled missing values, standardized data types, and optimized the dataset for analysis.
* **Business Insights:** Leveraged interactive visualizations to uncover patterns in consumer behavior and logistics.

## 🛠️ Tools & Technologies Used
* **Python** 
* **Pandas & NumPy:** Data wrangling and preprocessing
* **Plotly:** Interactive data visualization

## 📂 Dataset
The dataset contains over 100,000 anonymized orders placed between 2016 and 2018. Due to GitHub's file size limits, the raw CSV files are not included in this repository. 
You can download the dataset directly from [Kaggle's Olist Dataset Page](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/YourUsername/Olist-Ecommerce-Analysis.git`
2. Install the required dependencies: `pip install -r requirements.txt`
3. Download the dataset from Kaggle and adjust the file paths in the notebook to match your local directory.
4. Run the notebook using Jupyter or VS Code.
